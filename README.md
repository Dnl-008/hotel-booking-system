# Қонақүйді брондау ақпараттық жүйесі

Бұл жоба қонақүй бөлмелерін іздеу, брондау және брондауды басқару үшін арналған.

## Жүйенің негізгі мүмкіндіктері

- Қонақүй бөлмелерін іздеу
- Бос бөлмелерді тексеру
- Бөлмені брондау
- Қонақ туралы ақпаратты сақтау
- Онлайн төлем жасау
- Брондауды өзгерту немесе жою
- Брондау ақпаратын басқару

## Жүйе пайдаланушылары

- Қонақ
- Қонақүй қызметкері
- Администратор
