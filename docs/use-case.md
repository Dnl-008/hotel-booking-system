# Use Case

## Қонақ

- Жүйеге кіру
- Бөлме іздеу
- Бөлмені брондау
- Төлем жасау
- Брондауды өзгерту
- Брондауды жою

## Қонақүй қызметкері

- Жүйеге кіру
- Брондауларды басқару

## Администратор

- Жүйеге кіру
- Пайдаланушыларды басқару
- Бөлмелерді басқару

## Негізгі брондау сценарийі

1. Қонақ жүйеге кіреді.
2. Келу және кету күндерін енгізеді.
3. Жүйе бос бөлмелерді көрсетеді.
4. Қонақ бөлмені таңдайды.
5. Жеке мәліметтерін енгізеді.
6. Жүйе жалпы соманы есептейді.
7. Қонақ онлайн төлем жасайды.
8. Төлем сәтті болса, брондау расталады.
